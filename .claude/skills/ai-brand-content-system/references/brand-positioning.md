# Brand Positioning

## One-Line Position

Joe Black builds practical agentic development systems: Claude/Codex plugins, MCP tools, AI coding workflows, and automation patterns that expose what actually works.

## Brand Promise

Follow Joe to see real AI development systems shipped in public: the architecture, the mistakes, the workflow loops, the prompts, the tools, and the tradeoffs.

## Audience

Primary:

- Developers using AI coding agents seriously.
- Tool builders working with Claude Code, Codex, MCP, GitHub automation, and local-first workflows.
- Technical founders and senior engineers who want leverage without hype.

Secondary:

- AI-curious builders who want concrete workflows instead of generic prompt tips.
- Devtool users looking for installable plugins, reproducible setups, and workflow automation.

## Voice

Use:

- Direct, technical, field-tested.
- "Here is what broke, here is why, here is the fix."
- Specific tools, paths, commands, diffs, metrics, examples.
- Candid tradeoffs and implementation details.

Avoid:

- Generic AI futurism.
- Empty hustle language.
- Fake certainty about platform algorithms.
- "Everyone must use this" framing.
- Content that pretends AI wrote less than it did. Be transparent when AI materially assisted.

## Positioning Lanes

1. **Agentic stack field notes** - what works when Claude/Codex are real coworkers, not demos.
2. **AI coding agent failure analysis** - mistakes, loops, memory failures, evals, correction systems.
3. **MCP and plugin engineering** - practical tool surfaces, packaging, marketplace work, safety.
4. **Local automation and dev environment leverage** - macOS, repo skills, Obsidian, GitHub bots, Pi cluster.
5. **Public build logs** - shipped features, before/after demos, release notes with lessons.

## Default CTAs

Use CTAs that match the artifact:

- "Install the plugin."
- "Read the repo."
- "Try this workflow."
- "Steal the checklist."
- "Watch the demo."
- "Tell me where this breaks in your setup."

## Brand Red Lines

- Do not sell certainty about virality.
- Do not imply autonomous posting has been reviewed by the user unless it has.
- Do not create fake controversy.
- Do not claim benchmarks, platform rules, monetization eligibility, or tool availability without current verification.
