# Metrics And Experiments

Track learning, not vanity.

## Core Metrics

Per artifact:

- Source path/URL.
- Platform.
- Published URL.
- Date/time.
- Format.
- Hook.
- CTA.
- Hypothesis.
- Views/impressions.
- Watch time or retention if video.
- Clicks.
- Saves/bookmarks.
- Comments/replies.
- Shares/reposts.
- Newsletter subscribers.
- GitHub stars/forks/issues.
- Installs or traffic to marketplace/site.
- Qualitative feedback.

## Useful Experiments

- Hook A/B: failure-first vs result-first.
- Format: teardown vs tutorial vs launch note.
- CTA: repo install vs newsletter vs discussion prompt.
- Video proof: face + screen vs screen-only.
- Thread shape: concise single post vs 5-8 post thread.
- Reddit framing: question-first vs lesson-first.
- GitHub README: demo-first vs install-first.
- Newsletter cadence: weekly field notes vs project-specific drops.

## Scoring Content Ideas

Score 1-5:

- Proof strength: is there a real demo, repo, diff, or result?
- Audience pain: does a specific developer recognize the problem?
- Novelty: is this distinct from generic AI content?
- Reuse potential: can it become long form, short form, and GitHub docs?
- Brand fit: does it reinforce Joe's agentic development lane?

Prioritize ideas with total score 18+.

## Cadence

- 24 hours: early hook/packaging signal.
- 72 hours: short-form and social discussion signal.
- 7 days: durable engagement and click-through signal.
- 30 days: long-tail search, subscribers, repo traffic, install impact.
